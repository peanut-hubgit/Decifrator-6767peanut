# Código de conduta

## Nosso compromisso
Queremos um espaço aberto e respeitoso para colaboração, independentemente de experiência, identidade ou origem.

## Comportamento esperado
- Seja respeitoso e objetivo.
- Aceite críticas construtivas.
- Foque no que é melhor para o projeto.
- Não publique assédio, discriminação, ameaças ou informações privadas de terceiros.

## Aplicação
O mantenedor pode remover conteúdo ou restringir participação que viole estas regras. Para comunicar uma ocorrência, contate o mantenedor privadamente pelo GitHub.
