# Como contribuir

Contribuições são bem-vindas.

## Antes de enviar
1. Confira se já existe uma issue sobre o problema ou proposta.
2. Para mudanças grandes, abra uma issue para discutir a ideia.
3. Mantenha o projeto simples e compatível com navegadores modernos.

## Desenvolvimento
- A aplicação está concentrada em `Index.html`.
- Abra o arquivo diretamente no navegador para testar.
- Teste os fluxos principais, responsividade, tema claro/escuro e uso em telas pequenas.
- Evite adicionar dependências sem necessidade.
- Não inclua dados pessoais, credenciais ou segredos nos commits.

## Pull requests
Descreva o motivo da mudança, o que foi alterado e como testou. Se modificar a interface, inclua capturas de tela quando possível.
