# Política de segurança

## Escopo
Este projeto é uma aplicação web estática. Não foi projetado para proteger informações confidenciais nem para oferecer criptografia de segurança.

## Como reportar
Não publique detalhes de uma vulnerabilidade explorável em uma issue pública.
Se o recurso **Private vulnerability reporting** estiver habilitado na aba Security do GitHub, use-o. Caso contrário, entre em contato privadamente com o mantenedor pelo perfil do GitHub.

Ao reportar, inclua:
- descrição e impacto;
- passos para reproduzir;
- navegador e sistema operacional;
- captura de tela ou exemplo, se aplicável.

Não há SLA de resposta garantido. Relatos serão analisados conforme disponibilidade do mantenedor.
